# DynamicShopper identity during chat

The default marketplace uses the orange shopping header, a white DynamicShopper wordmark and a dark orange search action. Opening the shopping assistant leads to the adaptive receipt. There the wordmark remains recognizable, and each receipt theme supplies its own background, ink and action colors.

The brand browser suite checks both surfaces after real offline chat messages at phone and laptop sizes. The accessibility suite checks text across both languages and all four themes. The optional interview still opens a review with explicit Apply and Cancel actions.
